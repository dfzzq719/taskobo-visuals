# 场景、图片形式与画风

## 形式判断

“形式”决定信息如何组织，“画风”决定画面如何呈现。先选择前者。

| 内容主要关系或任务 | 推荐形式 | 风格与细节取舍 |
| --- | --- | --- |
| 解释一个抽象概念或价值 | 单一物件隐喻、概念插图 | 抽象几何、雕塑或编辑绘画；隐喻必须能被受众理解 |
| 表达前后变化或一次反馈 | 两状态对照、短分镜 | 界面混合、扁平或轻立体；保持同一对象，突出真正改变的部分 |
| 表达操作顺序、条件与异常 | 流程或决策图 | 线稿或线面结合；明确箭头、分支、停止/返回，减少材质装饰 |
| 表达系统依赖、责任与数据流 | 关系/架构图、分层图 | 技术线稿、模块符号；需要实体空间时再用轴测 |
| 比较方案或区别 | 同构对照、小倍图、矩阵 | 固定主题与比例，避免画面华丽程度代替比较事实 |
| 说明真实趋势、成本、数量 | 图表 | 从真实数据确定性绘图；配色区分系列或顺序，不另造装饰性数据 |
| 说明设备结构与装配 | 剖视、爆炸图、局部放大 | 技术线稿或准确渲染；真实结构依据比风格优先 |
| 说明人物协作、服务或交接 | 场景图、角色关系图 | 几何扁平或企业叙事插图；人物的动作说明关系，而非充当背景 |
| 产品引导、空状态、操作说明 | Spot 图、界面片段、真实截图 | 少量对象和简化背景；正文/操作提示与插图配合 |
| 封面或活动主视觉 | 概念 Hero、品牌隐喻 | 可增加艺术表达；减少信息节点，考虑标题区与裁切 |
| 用户只比较画风 | 同一主题的风格板 | 统一构图和配色，各格改变画法，名称或编号保持可读 |
| 用户只比较色系 | 同一图的色板变体 | 固定画法和布局，改变色相、明度或重点分配 |

大图缩到手机后需要依靠放大才能理解时，优先减少节点、改变为纵向关系或拆图。用户明确要“所有样式一张图”时保留总览，并提供可放大的原图；不要据此推断所有正式插图都应密排。

## 当前画法从一份目录选择

当前20种见[唯一共用目录](style-recipes.json)与[企业画法筛选](enterprise-style-curation.md)。普通报告优先线稿、平面和描边填色，技术、叙事、手绘、立体按用途选择；不把题材、视角、材质或界面混合的构图各算成一个新画法，也不再按早期20个探索标签创建第二套样式。插图与图标使用同一ID及完整画法。

## 单独记录的维度

- **视角**：二维正面、等距/轴测、半等距、透视、剖视、爆炸分解。等距可以与线稿、色块或渲染结合。
- **题材**：物件、界面、人物、角色、现场、抽象隐喻。人物/吉祥物并不是某一种画法。
- **材料**：真实对象有需要时可如实描绘，但不按每种材质另建通用企业画法。当前20种与停用理由见[企业画法筛选](enterprise-style-curation.md)。
- **布局**：网格、模块、自由编辑构图。瑞士式网格属于组织语言，不是必须套用的插画材质。
- **气质**：理性精密、现代科技、亲和温暖、成熟编辑、品牌鲜明。它来自多个视觉选择的组合。

| 来源 | 可借鉴的事实或原则 | 证据范围 |
