# 图片外形与透明背景

外形是构图/交付参数，不是另一种画风。它可以与统一样式目录中的每种画法组合；插图与图标仍共用同一个样式ID。无外框不等于删除物件自身的描边，也不能把选定的线稿改成无描边色块。

| `assets[].framing` | 外观 | `background` |
| --- | --- | --- |
| `freeform`（独立素材默认） | 主体与必要的场景片段形成自然外轮廓，外围透明，没有相框或几何底板 | `transparent` |
| `vignette` | 主体完整清楚，周边少量环境自然渐隐到透明；不是把整图模糊 | `transparent` |
| `full-scene` | 明确需要完整场景时，以环境铺满画布；不额外加相框 | `opaque` |

旧简报没有外形字段时，透明素材按 `freeform`，明确不透明的场景按 `full-scene`，不把已指定的完整背景改成透明。

已实际生成的[自然轮廓透明示例](../assets/examples/freeform/handover-enterprise-narrative.png)采用 `enterprise-narrative`，仅示范无外框构图和真实Alpha；当前内容仍由用户主题决定，不能把两名同事或交接清单变成默认对象。[制作记录](../assets/examples/freeform/handover-enterprise-narrative.json)保留实际检查范围。它不是其他画法的风格参考，也不代表所有画法均已生成验证。

## 自然轮廓的生成要求

先按无外框构图生成主体和必要环境，而不是仅对矩形照片抠背景。桌面、设备和局部环境可留下有意义的片段，不保留整面矩形墙、整块地板或装饰底座。避免相框、卡片、圆角矩形、椭圆裁切和无意义的大色块。关键人物、手部与物件完整；主体充分使用画面，只留适量安全透明边，不在画布边上突然切断。

透明PNG的文件画布仍是矩形，但透明区域在PPT、Word或网页中不可见，读者看到的是主体自然轮廓。需要独立素材时采用PNG真实Alpha；不把JPEG或绘制的棋盘格当作透明背景。参考图中的纸白、标题、边框和底板不能随画风一起带入。

`vignette`只改变外围Alpha处理，不给所有画法加水彩、烟雾、发光或模糊滤镜。主对象的颜色和表面保留；物件固有白色不应被一并抠除。阴影遵循选定样式；允许阴影的样式可保留渐隐半透明阴影，平面样式不为此添加体积投影。

## 简报示例

```json
{
  "direction": {"styleId": "enterprise-narrative"},
  "palette": {"roles": {"ink": "#0D2046", "primary": "#1456D9"}},
  "assets": [{
    "id": "handover-scene", "kind": "illustration",
    "meaning": "两人共同核对交接内容，尚未完成批准",
    "subject": "两名同事共同查看交接清单，只保留必要的局部桌面",
    "composition": "以清单和核对动作形成重心，人物与桌面形成自然外轮廓",
    "framing": "freeform", "background": "transparent"
  }]
}
```

运行统一的 `prepare_visual_jobs.py`，任务会保留 `framing`、透明背景参数及相应构图要求。工具中的“イラストの外形”只设置主插图外形；配套独立图标保持自然轮廓与透明背景，画法仍与主插图相同。

## 验图

实际查看Alpha，并把成图放到浅色、深色和文档主题底色上检查：是否仍有矩形残底、白边、被切断的主体、裁断的阴影或过大的透明留边。外围透明不代表已经具有自然轮廓；必须看图判断构图。规则和参数检查不等于样图已经生成或通过视觉验收。
