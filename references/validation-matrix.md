# 当前20种画法的验证矩阵

v0.6.0当前20种有效画法，10种旧画法停用；图标与插图始终一个ID和画法。9种有随包参照，但参照存在不等于所有题材、全部尺寸或用户均已认可。完整[日文证据矩阵](https://github.com/dfzzq719/taskobo-visuals/blob/main/docs/validation-matrix.ja.md)与[当前用途](enterprise-style-curation.md)分别说明。

| 画法 | 实际证据 | 范围 |
| --- | --- | --- |
| 单线、哑光立体 | assets/style-masters/monoline、matte-3d | 2026-11-05各1场景＋4图标总览，非独立图标交付 |
| 技术主题小插图 | assets/presets/technical-spot-compact.png | 既有图标和三文档验证，新场景配对未通过 |
| 企业叙事 | examples/service-story | 用户认可的3张宣传页，非独立Alpha图标 |
| 结构双色、几何多面 | assets/style-masters内对应ID | 原生SVG及PNG导出，1场景＋2图标，独立盲评确认；浅色文档色系 |
| 马克笔、彩铅、不透明水粉 | assets/style-masters内对应ID | 实际内置生图、1场景＋2图标、透明背景、独立盲评确认 |
| 清爽手绘 | 当前定义，无合格参照 | 位图和原生试作未形成与描边填色足够区分、完成度足够的手绘效果，不作母样 |

新5套只有一个虚构业务主题和一个蓝/青色系，未证明重复生成、任意文档、所有尺寸或公司采用。约640px场景和96px图标已查看；具体字体和全像素HEX不由此证明。总览不算多份独立文件。原生矢量与图像模型生成严格分开记录；两个已通过原生路线的新画法优先用SVG控制色面，再按需要导出透明PNG。

模型试作的结构双色、几何多面、清爽手绘各生成＋修正一次，因明暗偏差或画法重叠而未采用。清爽手绘的原生修订也没有因“算法可控”强行通过。不合格试作只留在维护输出目录，不混入当前参考。新位图作例的历史计划真实记录了当时加载的Skill0.5.0与新增画法目录0.6.0；没有事后改写版本。

机器测试检查共用定义、20/10目录及停用冲突、公司规范、生成计划、文件身份和原生SVG形式，不批准业务含义或审美。旧固定ZIP与已采用文件保持原字节，不因风格停用而修改历史交付。
