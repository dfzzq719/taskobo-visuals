# 从判断到生成与验图

## 可审阅的视觉简报

通常简短写明以下内容即可，不必每次展开为长报告：

- **读者任务**：看完能解释或辨认什么。
- **图片形式与依据**：关系/流程/对照/分镜/场景/单物件/图表等。
- **风格组合**：主导画法、视角、材质、布局、气质；指出它们服务于什么。
- **颜色方案**：依据和颜色角色，HEX 与必要对比检查。
- **显示环境**：最终尺寸、语言、背景、透明度、裁切与导出格式。
- **事实与不变量**：必须保留的对象和关系，真实还是教学模拟。
- **交付位置**：包括原图、提示词、中间结果的位置。

用户要求生成时，完成简报后直接生成。用户只要选型时，交付具体方案，不为补齐流程强行生成。已有明确授权不再重复确认。

## 提示词结构

```text
Asset and use: ...
Reader should see: ...
Form and reading order: ...
Subject and essential relationships: ...
Drawing treatment: ...
Viewpoint, material and composition: ...
Palette roles: background ..., ink ..., primary ..., focus ...
Reference roles: content / color / style / edit target ...
Exact labels, language and typography: ...
Output framing and transparency: ...
Preserve / avoid: ...
```

用可观察的要求替代空泛的“商务、高级、科技感”：例如“细而可靠的轮廓、规则角度、两种明度的色块、主关系不被阴影遮住”。形状、线条、空间、表面写清后，才补风格名称。

风格对照板指定格数、行列顺序、每格标签和共同主题；不要给各格塞不同故事。用户只比较风格时，参考配色固定。大范围颜色探索保持结构与画法固定。艺术方向探索可以组合变化，但让用户知道每版的变量。

图片中的短英文只是部分项目的可复用做法，不是普遍约束。用户或项目要求中文时按要求执行。密集或关键长文字放可编辑正文/排版层，避免把信息准确性押在图片生成的文字能力上。

## 验图时实际观察

1. 不看图注，主要对象和阅读顺序是否可辨？对照图中区别是否真正出现？
2. 必要箭头、关系、状态及角色是否准确？漂亮装饰是否改变了事实或暗示并不存在的结果？
3. 标签是否拼写正确，数据是否来自输入，示意是否被当成实测？
4. 最终显示尺寸上的文字与细线能否看清？整张图放大可读不代表缩略图也可读。
5. 所选颜色是否承担正确角色？状态或类别是否有非颜色线索？图像模型实际输出可能偏离 HEX，应查看成图而非只检查提示词。
6. 参考图约定、编辑不变量、透明背景、裁切和系列规则是否保留？

针对影响理解的问题做有目标的修订，再查看。不要在没有新增问题时不断扩大检查范围。交付时说明实际进行了哪些检查；计划、自动色板检查、视觉自查、独立读者反馈彼此不同。
