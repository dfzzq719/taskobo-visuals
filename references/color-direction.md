# 色系如何由内容确定

## 依据的优先顺序

1. 用户明确选择和可用的品牌约束。用户明确修改原有方向时遵循新要求并说明变化。
2. 当前项目的官方色板、CSS/设计令牌、系列图、周边网页或文档。令牌颜色的**角色**与色值一起读取。
3. 用户认可的颜色参考。区分颜色参考、风格参考、构图参考、必须保留的编辑目标。
4. 内容的主张、情绪和信息结构。先判断需要什么观感，再选择候选色相、明度与饱和度。
5. 行业习惯只补足空缺。没有“世界 500 强统一商务色系”，也不能以品牌知名度替代用户喜好。

没有品牌时，优先选择容易阅读、能跨多幅图保持稳定的中性色基底与有限强调色。展示候选而非宣称某色具有普遍心理作用。

## 哪些内容会改变颜色判断

| 内容线索 | 可尝试的颜色处理 | 核对什么 |
| --- | --- | --- |
| 精密、流程、责任、结构 | 明亮中性底、深色线条、克制主色 | 信息能否读清，重点是否稀释 |
| 关怀、服务、协作 | 温暖或柔和中性底、低到中饱和主体、少量焦点 | 避免把亲和画成幼稚；人物肤色另按主体处理 |
| 创新、未来、探索 | 受控双色/渐变、空间层次、适当饱和度 | 是否符合品牌，是否用光效掩盖无意义关系 |
| 风险、错误、事故或不可逆操作 | 主体保持正常语境，局部状态色和符号标出问题 | 不把全图变红，不使装饰红看起来像故障 |
| 正式研究、董事会或年报 | 稳定中性色、少量品牌色、清晰层次 | 高级感不依赖低对比灰字或金色装饰 |
| 多对象/类别比较 | 类别色稳定映射，并辅以标签、形状或线型 | 配色代表类别，而非无依据的好坏排序 |
| 数值递增或有明确中点的偏差 | 顺序色带或有依据的发散色带 | 中点、范围、正负语义来自数据而非审美猜测 |
| 印刷、灰度或投影 | 明度差、可靠轮廓和线型、适当留白 | 屏幕 sRGB 检查不代替印刷打样；无配置文件不保证 CMYK 精确 |
| 暗背景或暗模式 | 在实际背景上重新检查角色色和透明层 | 不简单反相，不直接沿用浅色模式的淡线 |

## 色板需要的角色

通常从背景、表面、主体/文字、弱化内容、主色、重点色开始。根据内容添加状态色、分类色或数据色，不为凑数量制造颜色。

给出角色 → HEX → 使用对象 → 选择依据，例如“焦点色 #B05727：只用于修改位置；来自用户希望突出差异的要求”。颜色面积用“背景占主导、主色承载对象、强调色少量”描述即可；未经用户或品牌规定，不固定 60/30/10 比例。

品牌主色是品牌身份；状态色表达具体状态。即便主色是红色，也不能把所有红色对象解释成错误。若红色主色与错误色近似，状态用符号、明确文字和位置进一步区分。

## 无品牌时的起始候选

以下为原创起点，按角色重新检查，不是自动按行业套用的模板。顺序为：背景 / 主体文字 / 主色 / 少量强调。

| 名称 | 色值 | 建议选择依据 |
| --- | --- | --- |
| 明亮理性 | #F8FAFC / #18283F / #2457A6 / #B85B32 | 清楚、稳重、流程或结构阅读 |
| 温暖中性 | #F6F2EA / #2C302F / #49695A / #A45B35 | 人本、协作、成熟出版物 |
| 深墨与青绿 | #F7FAF8 / #173342 / #007F78 / #B05727 | 克制科技与温和服务之间的平衡 |
| 中性与朱红 | #FAF8F5 / #302B2B / #A83D35 / #536478 | 用户指定鲜明主色或强品牌重点 |
| 石墨与琥珀 | #F8F7F3 / #292E35 / #4C6179 / #98601B | 正式编辑、少量温暖焦点 |
| 暗底与冷光 | #101B2B / #F2F5FA / #80B6FF / #F0B378 | 实际暗色环境或用户明确想要的方向 |

参考图中最常见的颜色未必是品牌主色，例如纸底、天空或皮肤会占大面积。没有像素分析时用“视觉估计”，不报告虚构的提取百分比。透明图像在实际承载背景上检查；不同背景需分别验证。

## 对比度检查

下面的阈值来自 WCAG 2.2 的数字内容要求；本技能也把它们作为说明图的实用设计检查，不据此对印刷或整幅作品宣布合规。

- 有信息意义的普通文字及文字图像通常检查 4.5:1。大字可用 3:1，但必须按实际显示尺寸判断，不能因为生成母版里的字很大就算大字。
- 为理解所必需的图形或控件相关视觉信息，在适用时检查与相邻颜色的 3:1；装饰背景、非必要阴影不机械套用。
- 颜色不能单独承担必要信息。对照、状态和数据采用标签、形状、位置或线型补充。
- 比较使用未舍入的比值。渐变、透明或纹理色对需要实际合成背景和最差位置；工具仅计算指定的不透明纯色对。

```text
python scripts/check_palette.py --foreground '#173342' --background '#F7FAF8' --minimum 4.5
python scripts/check_palette.py --palette assets/palette-example.json
```

退出码：0=所有所选色对达到其阈值；1=有未达到的色对；2=输入错误。JSON 只输出到标准输出，需要保存时写入授权产物目录。工具不生成或修改图片，不判断类别色是否色盲可分，也不判断语义是否合理。
