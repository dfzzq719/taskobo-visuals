# 画法と実生成の検証範囲

[現在の20種](icon-styles.ja.md) · [公開README](../README.md) · [会社基準と実行](enterprise-standard.ja.md)

v0.6.0は20種の有効画法と10種の廃止記録を分けて管理する。イラストとアイコンは一つのID・描画定義を共有する。画法の妥当性、例の生成、独立納品、ユーザー採用は別の確認事項だ。

| 画法 | 実際の証拠 | 確認した範囲 |
| --- | --- | --- |
| モノライン | [画像・プロンプト・記録](../assets/style-masters/monoline/) | 2026-11-05の1場面＋4図柄総覧、浅色資料向け。独立PNGの納品ではない |
| マット3D | [画像・プロンプト・記録](../assets/style-masters/matte-3d/) | 2026-11-05の1場面＋4図柄総覧、同じマットな描画 |
| テクニカルスポット | [コンパクト参照](../assets/presets/technical-spot-compact.png) | 既存図柄と3文書12図柄の検証。新たな場面とのペアは未完了 |
| 企業叙事 | [利用者が確認した3ページ](../examples/service-story/) | 文字・図柄・場面を含むページ画像。独立Alpha図柄ではない |

| 色鉛筆 | [原図・記録](../assets/style-masters/colored-pencil/) | 2026-11-06の1場面＋2図柄。内蔵画像生成、独立したAgentによる盲評 |

新たな5例は、同じ架空の資料確認・引継ぎ、青・ティール配色を使った。これは単一テーマ・単一配色の確認で、全業種、全サイズ、繰返し生成での一致を保証しない。実表示サイズでおよそ640pxの場面と96pxの図柄を確認したが、正確な文字・字体の検証ではない。図柄を含む総覧は独立ファイルの納品として数えない。

初回の原生参照制作に先立つ画像モデルの試作は、構造デュオトーン、幾何ファセット、クリーン手描きで各1回修正しても要件に届かなかった。柔らかい明暗や画法の重複を、見た目の良さで合格にしなかった。構造双色と幾何多面は編集可能な図形を用いた別経路で実色面を確認した。クリーン手描きは原生版も含めた盲評で違い・完成度が不足し、参照なしの定義に留める。

マーカー・色鉛筆・ガッシュの実際の計画は、当時の読み込まれたSkill0.5.0と追加済みの画法ディレクトリ0.6.0を記録している。制作後に履歴を0.6.0へ書き換えていない。今回配布するSkillとディレクトリは0.6.0でそろえる。

このほかの有効画法は定義または歴史的な作例を持つが、新しいペアの実生成を確認したとしない。廃止した10種は新規制作の選択肢から外し、旧23種の画像を現行一覧として使わない。Agentレビューは利用者や企業の採用を意味しない。配色、透明な縁、業務の意味とシリーズの整合性は用途ごとに確認する。
