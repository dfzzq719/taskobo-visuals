# Taskobo Visuals 利用ガイド：企業向けイラスト・アイコンをAIで制作する

提案書、研修資料、報告書、Webに合うイラストとテーマ別アイコンを制作するAIエージェント用スキル（SKILL.md）。テーマ、画風、配色を別々に決め、チームの見本と制作基準を引き継ぐ。

[作品展示](https://taskobo.com/free-tools/taskobo-visuals/) · [23の画風・素材の作例](icon-styles.ja.md) · [業種別サンプル](gallery.ja.md) · [Skill本体](../SKILL.md)

[TaskoboのAIスキル一覧](https://taskobo.com/skills/)で用途を比較できる。議事録からWBS・責任分担表・工程表を更新する場合は、[Taskobo Diagrams](https://taskobo.com/free-tools/taskobo-diagrams/)を参照する。

## まずサンプルで確かめる

[展示ページ](https://taskobo.com/free-tools/taskobo-visuals/)は作品の比較、[制作ツール](https://taskobo.com/free-tools/taskobo-visuals/tool/)は条件の設定とSkillの導入に使う。業種別サンプルから制作ツールに進むと、そのテーマと配色が入力される。

製造・物流、小売・サービス、医療・ケア、教育・研修の4ページを公開している。各ページでイラスト1点とアイコン6点を確認し、SVGの配色を比較できる。サンプル一式にはイラストのPNG、独立したSVG・透明PNG、元の配色、依頼文と生成プロンプトが入る。

配色プレビューはアイコンだけに適用する。上のイラストやダウンロード素材は元のサンプル配色のまま。架空の場面を使った作品例であり、実企業の導入事例ではない。

## Skillを追加する

1. [Releases](https://github.com/dfzzq719/taskobo-visuals/releases)または[制作ツールの導入欄](https://taskobo.com/free-tools/taskobo-visuals/tool/#install)からSkill ZIPを保存する。
2. 展開した `taskobo-visuals` フォルダー全体を、利用するAIソフトのSkill対応ディレクトリに置く。
3. セッションを再読み込みし、`$taskobo-visuals` と制作条件を渡す。

Skill本体の説明文は現在、中国語。日本語の利用ガイドと依頼文・サンプルは[公開ページ](https://taskobo.com/free-tools/taskobo-visuals/)と[制作ツール](https://taskobo.com/free-tools/taskobo-visuals/tool/)で確認でき、業種別の素材は別のサンプル一式から保存する。必要な出力言語を指定して使う。インストール先は利用ソフトによって異なる。

## テーマ・画風・配色を決める

イラストとアイコンは、同じスタイルIDと完全に同じ画法を使う。小さなアイコンでは細部を減らすが、別の似た画風には置き換えない。スタイルは一つの定義で追加・変更・廃止し、両方の制作に反映する。

- **内容テーマ**：読者にどの仕事、行動、関係を伝えたいか。
- **画風**：イラストとアイコンで同じ線、塗り、材質、質感、光を使い、大きさに応じて構図と細部の量を調整する。
- **色系**：自社の指定色、文書の用色、推薦色。主色だけでなく濃色、浅色、背景の役割を決める。

[制作ツール](https://taskobo.com/free-tools/taskobo-visuals/tool/)で条件を入力すると、依頼文と制作ブリーフJSONをブラウザー内で作成できる。ここではAI生成を実行せず、文書もアップロードしない。作った依頼文を普段使っているAIに渡す。

「イラストの外形」で、自然な輪郭の透過素材、周辺を透明へなじませる素材、背景付きの全面イラストを選べる。標準は自然な輪郭・透過で、写真枠や四角い背景を付けない。画風を変えずに外形だけを指定する。物自体の輪郭線は残し、同じシリーズのアイコンは透過素材とする。JSONの `assets[].framing` と背景指定も依頼文に合わせて出力する。[外形の指定と確認](../references/image-framing.md)を参照。

```text
$taskobo-visuals を使い、新入社員のオンボーディングを説明する
社内研修用のイラスト1点と、テーマ別アイコン6点を制作する。
主色 #1456D9、濃色 #0D2046。配置先の文書は #FCFBF8、独立素材には塗らない。
日本語で配図計画と使用上の注意を示す。
編集可能な図形アイコンは独立SVGと透明PNGにする。
独立したイラストとアイコンの背景は透明にし、必要な柔らかい影は半透明で残す。
小サイズで確認し、採用する見本と生成プロンプトを保存する。
```

[23の画法・素材作例](icon-styles.ja.md)から方向を選べる。v0.3.5では対応する[23の画法レシピ](../references/style-recipes.json)もSkillに同梱する。Webの選択肢は3つの基本方向・2つの具体的なプリセットで、全レシピの設定画面ではない。作例番号と名称をAIへの依頼文に添え、今回の内容・表示サイズに合わせて制作する。

### 技術テーマのスポットイラスト

`technical-spot`（Technical Spot Illustration）は、簡潔な記号と詳しい場面イラストの中間にある、説明用の小さなイラスト。2Dの輪郭線と平面の色面で物の構造を伝える。少量の明度差は説明のために使い、球体の陰影、膨らみ、プラスチックの光沢、押出しの厚みは加えない。対象は自動車や機械に限らず、今回の業務テーマから選ぶ。配色は自社の指定色に変更できる。

独立素材は透明背景を標準とする。必要な影は薄い半透明として残し、白い縁、背景プレート、展示台は加えない。内蔵imagegenでは `transparent_background: true` を指定する。既存の試作見本の白い背景は画風を見るためのもので、新しい素材に引き継がない。完全な場面背景や色付きの比較表を明示した場合は、その指定に従う。実際のAlphaチャンネルと明暗両方の背景で輪郭を確認する。

[現在のコンパクト参照](../assets/presets/technical-spot-compact.png)と[画風の説明](../references/technical-spot.md)を参照する。参照画像は見てから画像生成ツールへ実際に渡す。画風は選択肢として採用済みだが、新しい見本は個別承認前の草稿。従来の[双視点の研究見本](../assets/presets/technical-spot.png)は履歴として残し、小さな図の密度を決める既定参照にはしない。どの視点でも装飾用の展示台、四角い支持台、下敷き板を加えない。

実際の表示が72–128px程度なら `compact` を使い、主対象1つと必要な補助1つまでを目安にする。端子、放熱フィン、配線、螺子、複数の計測器を詰め込まない。広い意味は本文に残し、図は見分ける役目を担う。大きな画像を細かく描いてから縮めるだけでは、小さな図の品質を保てない。

制作記録にはSkill版、配方ID、参照画像とハッシュ、実表示サイズ `iconSizePx`、`detailLevel`、配色を残す。`prepare_icon_jobs.py` はこの `styleLock` と実際に渡すべき参照を出力する。PPTの構造検査と、図の見え方の検査は別々に行う。

```text
$taskobo-visuals の technical-spot を使い、物流サービスの説明用イラストを4点制作する。
視点は side、台座は none。配色は当社の指定色を使う。
対象、構図、配色を見本からそのまま引き継がず、今回の業務内容から決める。
```

## 文書がある場合

PPTX、DOCX、Markdown、テキストから、ローカルの読取り専用スクリプトで文字と色の証拠を抽出できる。Python 3.10以上を使う。

```bash
python scripts/extract_context.py --input proposal.pptx > document-context.json
```

抽出器はテーマを決定しない。AIが抽出結果を読み、ページ・段落と引用を根拠にテーマと挿絵を提案する。DOCXの段落番号はページ番号ではない。Officeの標準テーマ色を正式な企業ブランド色と決めつけない。

各アイコンについて、根拠、伝える意味、描く物・動作、誤解させてはいけない条件をAIが整理する。例えば「承認待ち」を、見栄えのために「承認済み」のチェックへ変えない。対象と配色は今回の資料から決める。Agentが整理したアイコン用ブリーフは、`scripts/prepare_icon_jobs.py --brief brief.json --context document-context.json --output generation-jobs.json` で画法レシピと組み合わせられる。補助スクリプト自体は意味を推論せず、画像も生成しない。

[DOCX・PPTX・Markdownからの実生成検証](document-driven-validation.ja.md)では、新しい3業務・12アイコンを06の画法で制作した。これは06の具体的な検証であり、23画法すべての画質や任意文書の一回成功を保証するものではない。

PDFの文字抽出は追加の `pypdf` に依存する。画像内の文字、スキャン文書のOCR、ページ上の余白とレイアウト理解は、利用するAIの機能による。入力ファイルは変更しない。資料をAIへ渡す際は、そのソフトのデータ取扱いと社内ルールを確認する。

## できることと必要な環境

Skillは制作方法と補助スクリプトを提供する。画像生成には宿主AIの生成機能、ファイル保存やSVG作成にはローカルツールが必要。モデル、APIキー、Web画像生成バックエンドは同梱しない。

SVGは独立した図形で、PNGは透明背景のビットマップ画像。PNGをSVGファイルに埋め込んだだけのものを編集可能なベクター素材と扱わない。Web上での文書解析、課金、アカウント、素材庫、WordやPPTへの自動配置は今回の提供範囲に含まれない。

## 社内で共通の表現にする

採用する配色、線、画風、表示サイズ、承認済み見本を制作ブリーフと一緒に保存し、版を付けて共有する。管理者は同じSkillと見本を社員へ配布できる。

SVGは幾何と色値を固定できる。一方、生成式イラストはモデルや入力によって構図と細部が変わる。厳密な統一が必要なシリーズは、承認済みの見本を参照して作り、人が採用素材を確認する。

## よくある質問

### Webページだけでイラストやアイコンを生成できるか

Web制作ツールで作るのは依頼文と制作ブリーフJSONだ。画像は、Skillを導入したAIの画像生成機能で制作する。Webページでの画像生成、文書アップロード、WordやPPTへの自動配置は提供していない。

### 透過PNGや編集可能なSVGを保存できるか

独立したイラストとアイコンは、実際のAlphaチャンネルを持つ透明PNGを標準とする。図形として制作したアイコンは独立SVGで保存できる。画像生成で得たPNGをSVGに埋め込むだけでは、図形ごとに編集できる素材にはならない。

### 日本語の依頼文や手元の文書を使えるか

日本語の利用ガイド・依頼文を用意しているが、Skill本体の説明文は現在、中国語だ。出力言語を指定して使う。文書抽出にはPython 3.10+を使い、PPTX・DOCX・Markdown・テキストに対応する。PDFの文字抽出には追加の `pypdf` が必要で、OCRは利用中のAI環境の機能に従う。

### 無料のSkillを入れると、画像生成の費用も不要になるか

Skillのダウンロードに料金はかからない。画像生成の利用料・回数制限・出力上限は利用中のAIサービスや契約に従う。画像生成機能を備えたAIと、保存やSVG制作に必要なローカルツールを使う。モデル、APIキー、画像生成用のWebバックエンドは同梱しない。
