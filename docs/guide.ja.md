# Taskobo Visuals 利用ガイド

業務の内容を理解してから、イラストやテーマ別アイコンを制作するAI Skill。テーマ、画風、配色を別々に決め、チームの見本と制作基準を引き継ぐ。

[展示ページ](https://taskobo.com/free-tools/taskobo-visuals/) · [サンプル一覧](gallery.ja.md) · [Skill本体](../SKILL.md)

## まずサンプルで確かめる

[展示ページ](https://taskobo.com/free-tools/taskobo-visuals/)は作品の比較、[制作ツール](https://taskobo.com/free-tools/taskobo-visuals/tool/)は条件の設定とSkillの導入に使う。業種別サンプルから制作ツールに進むと、そのテーマと配色が入力される。

製造・物流、小売・サービス、医療・ケア、教育・研修の4ページを公開している。各ページでイラスト1点とアイコン6点を確認し、SVGの配色を比較できる。サンプル一式にはイラストのPNG、独立したSVG・透明PNG、元の配色、依頼文と生成プロンプトが入る。

配色プレビューはアイコンだけに適用する。上のイラストやダウンロード素材は元のサンプル配色のまま。架空の場面を使った作品例であり、実企業の導入事例ではない。

## Skillを追加する

1. [Releases](https://github.com/dfzzq719/taskobo-visuals/releases)または[展示ページ](https://taskobo.com/free-tools/taskobo-visuals/#install)からSkill ZIPを保存する。
2. 展開した `taskobo-visuals` フォルダー全体を、利用するAIソフトのSkill対応ディレクトリに置く。
3. セッションを再読み込みし、`$taskobo-visuals` と制作条件を渡す。

Skill本体の説明文は現在、中国語。日本語の依頼文とサンプルを同梱している。必要な出力言語を指定して使う。インストール先は利用ソフトによって異なる。

## テーマ・画風・配色を決める

- **内容テーマ**：読者にどの仕事、行動、関係を伝えたいか。
- **画風**：線、形、構図、立体感、細部の量。イラストと小さなアイコンで役割を分ける。
- **色系**：自社の指定色、文書の用色、推薦色。主色だけでなく濃色、浅色、背景の役割を決める。

[制作ツール](https://taskobo.com/free-tools/taskobo-visuals/tool/)で条件を入力すると、依頼文と制作ブリーフJSONをブラウザー内で作成できる。ここではAI生成を実行せず、文書もアップロードしない。作った依頼文を普段使っているAIに渡す。

```text
$taskobo-visuals を使い、新入社員のオンボーディングを説明する
社内研修用のイラスト1点と、テーマ別アイコン6点を制作する。
主色 #1456D9、濃色 #0D2046、背景 #FCFBF8。
日本語で配図計画と使用上の注意を示す。
編集可能な図形アイコンは独立SVGと透明PNGにする。
独立したイラストとアイコンの背景は透明にし、必要な柔らかい影は半透明で残す。
小サイズで確認し、採用する見本と生成プロンプトを保存する。
```

### 技術テーマのスポットイラスト

`technical-spot`（Technical Spot Illustration）は、簡潔な記号と詳しい場面イラストの中間にある、説明用の小さなイラスト。強弱のある輪郭線、控えめな色面、薄い明暗で物の構造を伝える。対象は自動車や機械に限らず、今回の業務テーマから選ぶ。配色は自社の指定色に変更できる。

独立素材は透明背景を標準とする。必要な影は薄い半透明として残し、白い縁、背景プレート、展示台は加えない。内蔵imagegenでは `transparent_background: true` を指定する。既存の試作見本の白い背景は画風を見るためのもので、新しい素材に引き継がない。完全な場面背景や色付きの比較表を明示した場合は、その指定に従う。実際のAlphaチャンネルと明暗両方の背景で輪郭を確認する。

[オリジナルの試作見本](../assets/presets/technical-spot.png)と[画風の説明](../references/technical-spot.md)を参照できる。画風は選択肢として採用済みだが、試作見本は個別承認前の草稿。上段は正面、下段は浅いアイソメトリックで、同じ4テーマを比較している。両段とも台座は付けない。本プリセットでは視点にかかわらず、装飾用の展示台、四角い支持台、下敷き板を加えない。

```text
$taskobo-visuals の technical-spot を使い、物流サービスの説明用イラストを4点制作する。
視点は side、台座は none。配色は当社の指定色を使う。
対象、構図、配色を見本からそのまま引き継がず、今回の業務内容から決める。
```

## 文書がある場合

PPTX、DOCX、Markdown、テキストから、ローカルの読取り専用スクリプトで文字と色の証拠を抽出できる。Python 3.10以上を使う。

```bash
python scripts/extract_context.py --input proposal.pptx > document-context.json
```

抽出器はテーマを決定しない。AIが抽出結果を読み、ページ・段落と引用を根拠にテーマと挿絵を提案する。DOCXの段落番号はページ番号ではない。Officeの標準テーマ色を正式な企業ブランド色と決めつけない。

PDFの文字抽出は追加の `pypdf` に依存する。画像内の文字、スキャン文書のOCR、ページ上の余白とレイアウト理解は、利用するAIの機能による。入力ファイルは変更しない。資料をAIへ渡す際は、そのソフトのデータ取扱いと社内ルールを確認する。

## できることと必要な環境

Skillは制作方法と補助スクリプトを提供する。画像生成には宿主AIの生成機能、ファイル保存やSVG作成にはローカルツールが必要。モデル、APIキー、Web画像生成バックエンドは同梱しない。

SVGは独立した図形で、PNGは透明背景のビットマップ画像。PNGをSVGファイルに埋め込んだだけのものを編集可能なベクター素材と扱わない。Web上での文書解析、課金、アカウント、素材庫、WordやPPTへの自動配置は今回の提供範囲に含まれない。

## 社内で共通の表現にする

採用する配色、線、画風、表示サイズ、承認済み見本を制作ブリーフと一緒に保存し、版を付けて共有する。管理者は同じSkillと見本を社員へ配布できる。

SVGは幾何と色値を固定できる。一方、生成式イラストはモデルや入力によって構図と細部が変わる。厳密な統一が必要なシリーズは、承認済みの見本を参照して作り、人が採用素材を確認する。
