# 業種別サンプル / Industry samples

架空の業務場面から制作したオリジナル。実企業の導入事例ではない。

## 製造・物流

検品、作業の確認、梱包と引渡し。工程を担う人の動きと、確かめる対象を一つの場面にまとめる。

![製造現場で部品と確認シートを照合する担当者、治具を説明する技術者、梱包する物流担当者のイラスト](../examples/manufacturing-logistics/illustration.png)

[Webで作品とアイコンを見る](https://taskobo.com/free-tools/taskobo-visuals/samples/manufacturing-logistics/) · [素材とプロンプト](../examples/manufacturing-logistics/)

## 小売・サービス

![店舗カウンターで返品の商品を確認する顧客とスタッフ、棚から交換品を用意する同僚のイラスト](../examples/retail-service/illustration.png)
